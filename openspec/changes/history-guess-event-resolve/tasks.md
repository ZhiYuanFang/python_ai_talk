## 1. 解析内猜测

- [x] 1.1 在事件解析阶梯之后，对父事件、未识别、多候选、软确认拉取最近约二十条历史并让模型在允许集合内选叶子；唯一叶子不猜
- [x] 1.2 猜中则改写为该叶子并打历史猜测标记；猜不中保持消歧、软确认或无法识别；查记录无编号时二十字猜测仍可用
- [x] 1.3 提示词放入喂养 system 常量；流式中文思考；中文业务注释

## 2. 执行与飞轮

- [x] 2.1 猜中后查、预测、新增、修改、结束计时直接继续；删除改为叶子确认，问句点出事件名，同意才落库
- [x] 2.2 历史猜测标记阻断事件说法飞轮（含删除确认成功后）；数量、时间、备注飞轮不关

## 3. 手工验收

- [ ] 3.1 手工：父事件或软确认在历史能对上时直接按叶子执行，且不写入事件说法
- [ ] 3.2 手工：删除猜中后先问再删；拒绝则不删
- [ ] 3.3 手工：猜不中仍消歧或无法识别；查记录仍无事件编号时回答不超过二十字
