## 1. 点查播报本地规则

- [x] 1.1 飞轮之前识别「上次 / 上一次 / 最近一次」为优先已完成、进行中只说正在进行
- [x] 1.2 「多久了 / 多长时间了」且不含上述词时为最近一条、进行中报已持续多久；「上次睡眠多久」不得走这一支
- [x] 1.3 规则命中则不查播报飞轮、不调播报模型；不中则保持原顺序

## 2. 父事件点查按开始时间选叶子

- [x] 2.1 仅查记录点查且事件为父节点时，按各子孙叶子最近一条的开始时间选定叶子，不调猜叶子模型
- [x] 2.2 开始时间相同取子孙列表中更靠前的叶子；选中结果不把整句写入说法飞轮
- [x] 2.3 这些叶子都没有历史时短问事件名；父下没有子孙叶子时保持未识别
- [x] 2.4 记一笔、修改、删除以及未识别、多候选仍走原路径
