## Context

`grounded-bestie-reply-prompts` 已要求有经验闺蜜 + 有据点名 + 约 50 字。产品反馈：回复仍像单向倾诉接待；希望追加引导式话题形成对话感，并可用同月龄「我家娃」代入。已拍板：约 80 字、点查也要引导、clinic + tip 都改。

## Goals / Non-Goals

**Goals:**

- Clinic/tip 提示强调文末尽可能一句引导（含点查：先事实后引导）。
- 月龄已知允许同月龄代入一句；未知禁止假同月龄。
- 字数目标改为约 80；更新测试断言。

**Non-Goals:**

- 不改图路由、向量、改写超时、Q&A 捷径答案润色。
- 不做程序化校验「是否带了问号」。

## Decisions

### 1. 仅增量改提示词

在现有 `clinic_answer` / `tip_answer` 上增加【对话感】【同月龄代入】块，并把「约 50 字」改为「约 80 字」；user 收尾可补一句「尽量以引导式问题收尾」。

### 2. 点查/汇总也引导，但不抢事实

顺序固定：**先**念准时间/趋势 → **再**一句轻引导。禁止用引导句替代可读时间。

### 3. 代入与「无据不编」边界

- 允许虚构闺蜜视角（「我家要是这月龄…」）。
- 禁止把代入写成对方宝宝的记录或「上次你说」（无 chat/history 时仍禁假记忆）。

### 4. 引导质量

优先：二选一、具体开放问；避免空壳「还有别的吗」、连续审讯式「为什么」。

## Risks / Trade-offs

- [80 字仍挤] → 点名 1 条 + 代入可选一句 + 引导一句；代入可弱于引导（「尽可能」引导优先）。
- [点查变啰嗦] → 明确先短答时间再引导。
- [代入像假人设过强] → 限一句、口语、非医嘱。

## Migration Plan

部署提示词即可；回滚恢复旧字符串。
