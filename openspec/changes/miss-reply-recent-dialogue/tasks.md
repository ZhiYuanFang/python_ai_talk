## 1. 十分钟对话窗

- [x] 1.1 按设备写入意图对外来回（原话、念出的回答、时间），TTL 10 分钟；与诊疗陪伴会话分开；空回答不记
- [x] 1.2 意图回答落定后追加本轮，漏答记自由回答而不是硬文案；确认句和落库回执同样记；Redis 失败不阻断回答

## 2. 注入漏答自由回答

- [x] 2.1 自由回答提示词加入窗口内更早的轮，整段约 800 字，放不下丢更早的轮，单轮过长只留前一段
- [x] 2.2 窗口为空则不写近况段；提示词说明近况只是背景；模型失败仍回退硬文案

## 3. 手工验收

- [ ] 3.1 先说一句再触发漏答，自由回答能接上刚才的话，且近况明显短于全部历史
- [ ] 3.2 超过 10 分钟或没有更早来回时，自由回答仍能用原话、画像和快照作答
