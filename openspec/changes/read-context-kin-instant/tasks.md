## 1. 日汇总语境

- [x] 1.1 非次数日汇总按吃了哪些、喝了多少、和昨天比分规则短答；禁止整段本地摘要加流水直出；次数问保持 N 次
- [x] 1.2 未覆盖语境：紧凑历史加原话走模型；规则缺口维度 history_speak_context；中文注释

## 2. 无事件编号

- [x] 2.1 无事件编号时按时间窗全量或点查全事件最近记录拉史；禁止无界；禁止追问查哪个事件
- [x] 2.2 模型回答不超过二十字；不写事件说法飞轮；规则缺口维度 history_missing_event
- [x] 2.3 消歧、软确认、无法识别、已对齐但无记录保持原路径

## 3. 亲属再试

- [x] 3.1 查史：父无行则用最近有记录的子事件并停止；子无行则只再试父一次
- [x] 3.2 预测：同样亲属规则；有信息指锚点或预约约定，不含样本不足文案

## 4. 非计时同一时刻

- [x] 4.1 新增与修改在非计时事件上开始与结束同一秒；冲突以结束时间为准；计时开表与闭合时长不改
