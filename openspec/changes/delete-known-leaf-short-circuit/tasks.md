## 1. 删除旁路短路

- [x] 1.1 删除且事件已是唯一叶子时，跳过备注明细、数量、时间，并清空反查或别名留下的备注

## 2. 纯删除定位

- [x] 2.1 本批只有删除且本地定位未命中时，策略直接为最近一条，不查定位飞轮、不调定位模型
- [x] 2.2 本地定位命中时采用该结果；本批含修改时仍走既有定位解析
