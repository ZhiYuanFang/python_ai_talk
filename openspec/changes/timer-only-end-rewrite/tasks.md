## 1. 对齐后收回结束操作

- [x] 1.1 事件类型已知后：轨已是更新且不是计时，子操作从 `end` 改回 `update`；计时仍保留 `end`
- [x] 1.2 落库收集：非计时的 `end` 改为 `update`，不再改成新建

## 2. 无进行中只改计时

- [x] 2.1 无进行中转补记只处理计时叶子；非计时不查进行中、不改成新建
- [x] 2.2 计时有进行中仍结束；没有进行中仍走现有补记或追问起止

## 3. 手工验收

- [ ] 3.1 非计时更新句里带「好了」或「结束」时落库是修改，不是新建
