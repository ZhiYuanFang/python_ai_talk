## 1. 口语日期

- [x] 1.1 紧凑历史日标签改为「M月D日」，跨年改为「YYYY年M月D日」；中文注释
- [x] 1.2 日汇总兜底与预测兜底提示词要求用几月几号，禁止连字符日期

## 2. 说话对象

- [x] 2.1 诊疗、查史兜底、无事件短猜、预测兜底、失败后直接回答，以及给家长看的成长轨迹与留意提示词，写明对方是孩子的家长，禁止称宝妈、宝爸或妈妈
- [x] 2.2 事件解析、分句、时间与数量等内部提示词不改角色句
